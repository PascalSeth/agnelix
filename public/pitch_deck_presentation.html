Autonomous Agent Triad (LangGraph)

Agnelix uses LangGraph state-machines to coordinate specialized agents with error fallback loops.

Agent 1: The Scout

Finds Intent Events

Queries APIs for negative reviews, hiring alerts, and tech shifts.

Agent 2: The Profiler

Finds Key Contact

Pulls owner name/verified email via LinkedIn and Apollo API.

Agent 3: The Closer

Outreach & Booking

Drafts specific hooks, classifies responses, and books Calendly.

💡 **Self-Improving Loop:** If Closer hits an objection, agent analyzes prompt outcomes and updates next batch hooks automatically.
